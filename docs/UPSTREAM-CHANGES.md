# Changes to the vendored wezterm tree

Base: [wezterm `20240203-110809-5046fc22`](https://github.com/wez/wezterm/releases/tag/20240203-110809-5046fc22)
(source tarball `wezterm-20240203-110809-5046fc22-src.tar.gz`). Everything under
`wezterm/` is that tree plus the patches below. Generated by diffing against the
pristine tarball (`diff -rq`, excluding `target/`).

## New crates (not in upstream)

| Path | What |
|------|------|
| `wezterm/wezterm-ios-core/` | The iOS client core: engine thread, TCP transport, PaneState→Snapshot conversion with color resolution, UniFFI (proc-macro) API, `examples/smoke.rs` (end-to-end test against a live mux via `WEZTERM_MUX_ADDR`), diagnostic `examples/probe.rs` / `probe2.rs` |
| `wezterm/poc-attach/` | Headless CLI mux client used to validate the protocol before any iOS work. Transports: `ssh <host>` (spawns `wezterm cli --prefer-mux proxy`) and `tcp <addr>`. Modes: `list`, `attach` (raw-tty interactive), `selftest` (spawns/kills its own pane in workspace `poctest`) |
| `wezterm/termwiz/src/terminal/unix_ios.rs` | Minimal substitute module for iOS providing only the pipe-based `UnixTerminalWaker` (the full unix terminal impl needs `termios`, which doesn't build on iOS) |

## Modified upstream files

### openssl removal (the app must not link openssl)

The dependency chain `config → wezterm-ssh → libssh-rs/ssh2 → openssl-sys` breaks iOS
cross-compilation and is unnecessary: the client only needs wezterm-ssh's pure-Rust
`ssh_config` parser.

| File | Change |
|------|--------|
| `wezterm-ssh/Cargo.toml` | backend features `libssh-rs` / `ssh2` made explicit and optional; `async_ossl` (openssl vendor helper) now optional, pulled only by a backend |
| `wezterm-ssh/src/lib.rs` | removed the "must enable a backend" `compile_error!`; all backend modules/re-exports gated behind `#[cfg(any(feature="libssh-rs", feature="ssh2"))]`; the pure-Rust `config` module always available |
| `config/Cargo.toml` | `wezterm-ssh` with `default-features = false` (parser only) |
| `mux/Cargo.toml` | new `ssh-domain` feature (default on) owning the `wezterm-ssh` dep; iOS builds use `default-features = false` |
| `mux/src/lib.rs` | `pub mod ssh` gated behind `ssh-domain` |
| `mux/src/localpane.rs` | `WrappedSshPty` downcast gated behind `ssh-domain` (with a `false` fallback) |
| `codec/Cargo.toml` | `mux` with `default-features = false` |
| `Cargo.toml` (workspace) | added `poc-attach`, `wezterm-ios-core` members |

Desktop/server builds are unaffected: feature unification via the binaries keeps
`ssh-domain` (and thus the ssh backends) enabled there.

### iOS target portability

Crates that don't compile for `aarch64-apple-ios*`, stubbed or gated where the
functionality is meaningless on a phone:

| File | Change |
|------|--------|
| `pty/Cargo.toml`, `pty/src/lib.rs` | `serial` dep (serial-unix → ioctl-rs, no iOS build) moved behind `cfg(not(target_os = "ios"))` |
| `mux/Cargo.toml`, `mux/src/domain.rs` | same gating for serial-port domains |
| `termwiz/Cargo.toml` | `termios` dep excluded on iOS |
| `termwiz/src/terminal/mod.rs` | on iOS, substitute `unix_ios.rs` (waker only); full impl kept for other unixes |
| `termwiz/src/lineedit/mod.rs` | `new_terminal`-dependent API gated off on iOS |
| `wezterm-blob-leases/Cargo.toml`, `src/lease_id.rs` | `mac_address` crate excluded on iOS; random node id fallback |
| `config/src/config.rs` | `RLIMIT_NPROC` ulimit check gated off on iOS (constant doesn't exist there) |

### Rust forward-compatibility (tree is from early 2024; built with Rust 1.96)

| File | Change |
|------|--------|
| `config/src/lua.rs` | `.eval()` → `.eval::<()>()` (never-type-fallback hard error in newer Rust) |

(`Cargo.lock` differs accordingly: new crates + uniffi and their transitive deps.)

## Reproducing the diff

```bash
curl -LO https://github.com/wez/wezterm/releases/download/20240203-110809-5046fc22/wezterm-20240203-110809-5046fc22-src.tar.gz
tar xzf wezterm-20240203-110809-5046fc22-src.tar.gz
diff -rq wezterm-20240203-110809-5046fc22 wezterm --exclude=target
```
